### Задание 2

### SYN-сканирование

Команда:

```bash
sudo nmap -Pn -sS \
  -p 21,22,23,25,80,139,445,3306,6667,65000 \
  --reason \
  192.168.56.101
```

При SYN-сканировании клиент отправляет TCP-пакет с флагом `SYN`.

Открытый порт отвечает пакетом `SYN, ACK`, после чего Nmap отправляет `RST`, не завершая установку соединения.

Закрытый порт отвечает пакетом `RST`.

### FIN-сканирование

Команда:

```bash
sudo nmap -Pn -sF \
  -p 21,22,23,25,80,139,445,3306,6667,65000 \
  --reason \
  192.168.56.101
```

Nmap отправляет TCP-пакет только с флагом `FIN`.

Закрытый порт отвечает `RST`. Открытый порт обычно не отвечает, поэтому результат может отображаться как `open|filtered`.

### Xmas-сканирование

Команда:

```bash
sudo nmap -Pn -sX \
  -p 21,22,23,25,80,139,445,3306,6667,65000 \
  --reason \
  192.168.56.101
```

При Xmas-сканировании устанавливаются флаги:

```text
FIN, PSH, URG
```

Закрытые порты отвечают `RST`, открытые порты обычно не отвечают. Поэтому открытые порты могут определяться как `open|filtered`.

### UDP-сканирование

Команда:

```bash
sudo nmap -Pn -sU -sV \
  -p 53,67,68,69,111,123,137,161,500,2049,65000 \
  --reason \
  --max-retries 1 \
  192.168.56.101
```

При UDP-сканировании TCP-флаги не используются.

Если UDP-служба отвечает, порт определяется как открытый.

Если сервер возвращает ICMP `Destination Unreachable: Port Unreachable`, порт определяется как закрытый.

Если ответ отсутствует, порт часто определяется как `open|filtered`.

### Сравнение режимов

| Режим | Отправляемый пакет  | Открытый порт            | Закрытый порт         |
| ----- | ------------------- | ------------------------ | --------------------- |
| SYN   | TCP `SYN`           | `SYN, ACK`               | `RST`                 |
| FIN   | TCP `FIN`           | обычно нет ответа        | `RST`                 |
| Xmas  | TCP `FIN, PSH, URG` | обычно нет ответа        | `RST`                 |
| UDP   | UDP-датаграмма      | UDP-ответ или нет ответа | ICMP Port Unreachable |

SYN-сканирование позволяет достаточно точно различить открытые, закрытые и фильтруемые порты.

FIN- и Xmas-сканирование могут вернуть состояние `open|filtered`, поскольку отсутствие ответа не позволяет определить, открыт порт или трафик блокируется.

UDP-сканирование обычно медленнее, поскольку многие UDP-службы не отвечают на пустые запросы, а ICMP-сообщения могут ограничиваться системой.
